# Student-dropout-risk-prediction
Student dropout risk analysis and early warning dashboard using Excel, SQL,Python and Power BI.
An education analytics capstone project exploring factors associated with student dropout and how data can support early identification and student-retention decisions.
Project Team: INNOVATHERS — Group 13
Programme: Tech4Dev Women Techsters Bootcamp, Cohort 5.1
# Project Overview
Student dropout is an important challenge for educational institutions. This project analyses student data to identify patterns associated with dropout and presents the findings through a Power BI dashboard.
The goal is to help educational institutions understand student trends and identify areas where additional support may be needed.
# Project Objectives
- Explore factors associated with student dropout.
- Clean and prepare student data for analysis.
- Use SQL and Python to explore patterns in the dataset.
- Build Power BI dashboards to communicate findings.
- Recommend practical ways to support student retention.
# Dataset
The cleaned dataset contains 9,500 student records and 19 intended analysis variables.
The variables cover areas such as:
- Student demographics
- Attendance and study hours
- Assignment submission delays
- Stress index
- GPA and CGPA
- Internet access
- Scholarship status and part-time employment
- Department, semester and parental education
- Dropout status
# Tools Used
- Excel: Data preparation and exploratory analysis
- SQL: Queries to explore student characteristics and dropout patterns
- Python: Exploratory data analysis and visualisation
- Power BI: Dashboard development and KPI reporting
- GitHub: Project documentation
# Key Findings
The project report highlights the following patterns:
- The reported dropout rate was approximately 23.6%, representing 2,241 students.
- Students who dropped out had a higher average stress index than students who remained enrolled.
- Students who dropped out had lower average attendance and study hours.
- Internet access and part-time employment were associated with differences in dropout rates.
These findings describe associations in the dataset and do not prove that any single factor causes student dropout.
# Recommendations
The project report recommends exploring:
- Early academic alerts and advisor follow-up
- Attendance monitoring
- Stress-management and counselling support
- Study-skills and time-management assistance
- Support for students facing internet-access or work-study challenges
These are proposed actions and have not been presented as tested interventions.

Predictive modelling methodology and evaluation metrics should be documented separately before making claims about model performance.
